# Learnings that change how Claude works

- When you create or edit a learning, ask whether it would change how Claude plans or does work in a future session. If it does, propose the lesson to the user: the fact, the lesson, how to apply it; nothing the learning file already argues.
- First look for a memory that already covers the subject and propose a line there; create a new memory only when none fits. Use a shared group (`/share-memories`) when the lesson holds outside this repo.
- Skip what the environment already enforces (`sandbox/AGENTS.md`, `Dockerfile`, a skill) and pure infrastructure facts.
