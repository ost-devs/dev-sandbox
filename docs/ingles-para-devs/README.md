# Inglês para devs

O que é feito para a IA ler (nomes de skills, comandos, instruções) fica em inglês: é a língua
em que os modelos e as ferramentas foram treinados e documentados, e um nome em inglês costuma
ser mais curto e mais previsível para o Claude. Esta pasta existe para que isso não vire uma
barreira para quem não lê inglês.

| Material | Para quê |
|---|---|
| [Glossário](./glossario.md) | O que significa cada nome e comando em inglês das skills deste repositório, com pronúncia aproximada |

Algumas skills mais antigas têm nome em português (`montar-consultor`, `estudar`), porque o
comando é mais intuitivo assim para quem não lê inglês. Elas podem continuar assim.
